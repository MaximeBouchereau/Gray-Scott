# Gray-Scott
Approximation of Gray-Scott model (Nonlinear coupled reaction-diffusion PDE modelling Virus-Food interaction)

- Files:
  - TooBox.py: File containing main elements of the code: Vector fields for nonlinearities, operators, solution prints tools...
  - Virus_Food_PDE.py: File containing parameters and integration methods of a solution by taking parameters dictionnary as input.

- Versions:
  - numpy: 2.4.1
  - scipy: 1.17.0
